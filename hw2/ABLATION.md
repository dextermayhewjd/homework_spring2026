## 问题：全因子太贵

hw2 实验 4 要调 4 个超参，每个取 3 档：

| 因子 | 三档 |
|---|---|
| A `--discount` | 0.95 / 0.99 / 1.0 |
| B 网络 `-l/-s` | 2/32 / 2/64 / 3/128 |
| C batch `-b` | 500 / 1000 / 2000 |
| D `-lr` | 5e-3 / 1e-2 / 2e-2 |

全因子 = $3^4 = 81$ 组。每组 15 万环境步，跑不起。

**但我们不需要 81 组的全部信息。** PDF 问的是
"which hyperparameters mattered" —— **要的是主效应，不是完整响应面**。

---

## 为什么不能随便抽 9 组

实测：从 81 组里**随机抽 9 组，重复 20 万次，正交的有 0 次**。

正交不是碰运气能碰到的性质，必须构造。

## L9 是什么

**L9(3⁴) = 9 行 × 4 列，每列 3 个水平的正交表。** 它是 81 组里特定的 9 组：

| # | A discount | B 网络 | C batch | D lr |
|---|---|---|---|---|
| 1 | 0.95 | 2/32 | 500 | 5e-3 |
| 2 | 0.95 | 2/64 | 1000 | 1e-2 |
| 3 | 0.95 | 3/128 | 2000 | 2e-2 |
| 4 | 0.99 | 2/32 | 1000 | 2e-2 |
| 5 | 0.99 | 2/64 | 2000 | 5e-3 |
| 6 | 0.99 | 3/128 | 500 | 1e-2 |
| 7 | 1.0 | 2/32 | 2000 | 1e-2 |
| 8 | 1.0 | 2/64 | 500 | 2e-2 |
| 9 | 1.0 | 3/128 | 1000 | 5e-3 |

（对应全因子表里的第 1, 14, 27, 33, 43, 47, 62, 66, 76 组。）

### 构造法：三行模 3 算术

不用背表，能算出来：

```
行 = (a, b) 遍历 {0,1,2}²        -> 恰好 9 行
col1 = a
col2 = b
col3 = (a + b)  mod 3
col4 = (a + 2b) mod 3
```

前两列穷举所有 $(a,b)$；后两列是前两列的**两个不同线性组合**。
因为 3 是质数，$+b$ 和 $+2b$ 在模 3 下是两个不同的双射 —— 这保证任意两列正交。

这是 **GF(3) 上的标准构造**。Taguchi 把常用的（L4/L8/L9/L16/L18/L27）做成了表，查即可。

> 想要 4 个因子 × 3 水平以上的设计：L18 能放 1 个 2 水平 + 7 个 3 水平因子；
> L27 能放 13 个 3 水平因子。列数越多，能估的交互越少。

## 核心机制：平衡性如何分离效应

这是整份文档最重要的一节。

### 观察 batch 的三组分别含什么

```
batch= 500  ->  run #1, #6, #8
    discount 取到  0.95, 0.99, 1.0    <- 三档各一次
    网络     取到  2/32, 3/128, 2/64   <- 三档各一次
    lr       取到  5e-3, 1e-2, 2e-2   <- 三档各一次

batch=1000  ->  run #2, #4, #9
    discount 取到  0.95, 0.99, 1.0    <- 三档各一次
    网络     取到  2/64, 2/32, 3/128   <- 三档各一次
    lr       取到  1e-2, 2e-2, 5e-3   <- 三档各一次

batch=2000  ->  run #3, #5, #7
    discount 取到  0.95, 0.99, 1.0    <- 三档各一次
    网络     取到  3/128, 2/64, 2/32   <- 三档各一次
    lr       取到  2e-2, 5e-3, 1e-2   <- 三档各一次
```

**三组的「其他因子构成」完全相同**，唯一系统性差异就是 batch。

### 形式化

把指标建模成各因子效应之和（**这就是「交互弱」这个假设**）：

$$y = \mu + \alpha_{\text{discount}} + \beta_{\text{网络}} + \gamma_{\text{batch}} + \delta_{\text{lr}} + \epsilon$$

对 batch=1000 的三组求平均：

$$\bar y_{b=1000}=\mu+\underbrace{\frac{\alpha_1+\alpha_2+\alpha_3}{3}}_{\text{三档全占}}+\underbrace{\frac{\beta_1+\beta_2+\beta_3}{3}}_{\text{三档全占}}+\gamma_{1000}+\underbrace{\frac{\delta_1+\delta_2+\delta_3}{3}}_{\text{三档全占}}+\bar\epsilon$$

**带下划线的三项对三个 batch 组完全一样**（这正是平衡性保证的）。所以：

$$\bar y_{b=1000}-\bar y_{b=500}=\gamma_{1000}-\gamma_{500}$$

**其他因子的影响被减掉了。** 这就是「9 组顶 81 组」的全部道理 ——
不是信息凭空多出来，而是**设计让噪声以外的干扰项互相抵消**。

## 怎么算主效应

一行公式：

$$\text{主效应}(f, v)=\frac{1}{3}\sum_{\text{含 }f{=}v\text{ 的那 3 组}}\text{指标}$$

hw2 实验 4 的实测（指标：达标后 Eval ≥950 的迭代占比，越高越稳）：

| 因子 | 水平 | 主效应 | 极差 |
|---|---|---|---|
| discount | 0.95 / 0.99 / **1.0** | 53% / **63%** / 41% | 22% |
| 网络 | **2/32** / 2/64 / 3/128 | **73%** / 51% / 31% | 42% |
| batch | 500 / **1000** / 2000 | 42% / **71%** / 43% | 28% |
| lr | **5e-3** / 1e-2 / 2e-2 | **76%** / 51% / 29% | 47% |

**极差（range）= 该因子最好水平与最差水平的差 = 它的重要性。**
这直接回答「哪些超参真正起作用」。

> 换个指标（首次到 1000 的步数），排序会变 —— batch 的极差跃升到 85,823 步，
> 成为第一重要。**所以指标必须先定清楚，而且最好看多个**（见下）。

## 三条必须遵守的前提

### ① 各组预算必须相同

指标是「首次达到目标的环境步数」时，**每组的总步数预算必须一样**，
否则比的是「谁跑得久」不是「谁配置好」。

hw2 的做法：固定 150K 步，`-n = 150000 / -b`。
所以 `-b 500` 跑 300 次迭代、`-b 2000` 跑 75 次 —— **迭代数不同是对的，步数相同才是关键**。

### ② 单一指标会骗人

hw2 的 #8（γ=1.0, 2/64, b500, lr2e-2）：

- 「首次到 1000」**22,434 步，全场最快** → 单看这个是最优配置
- 实际曲线：冲到 1000 后**归零，之后一路平在 0 再没起来**（策略崩溃）
- 末 10 轮均值 **3**，达标后 ≥950 的占比 **8%**

**只看一个数会把死掉的配置评为最优。** 至少要三个维度：

| 维度 | 指标 |
|---|---|
| 快不快 | 首次达标的环境步数 |
| 稳不稳 | 达标后 ≥95% 目标值的迭代占比、末 10 轮均值 |
| 形态 | 看曲线 |

### ③ 曲线形态用来诊断，不只是评分

数字说好坏，形状说**为什么**以及**往哪调**：

| 形状 | 含义 | 该往哪调 |
|---|---|---|
| 单调上升后贴顶 | 真学会了 | 就是它 |
| 上升后反复横跳 | 梯度方差大，守不住 | 加大 batch / 降 lr |
| 冲顶后归零不恢复 | **策略崩溃** | 大幅降 lr |
| 单调上升但慢 | 健康但保守 | 提 lr / 减 batch |
| 几乎不动 | 学不起来 | 换配置或查实现 |

九组画成 3×3 small multiples，不要叠成一张 —— **超过 4 条曲线叠加就读不了**。

## 诊断：这条主效应能不能信

主效应是 3 组的**平均**，而平均会掩盖分歧。**组内极差**是可信度判据：

| 情况 | 三组结果 | 平均 | 这个平均代表什么 |
|---|---|---|---|
| 一致 | 88% / 77% / 62% | 76% | ✅ 「这个水平就是好」 |
| 分歧 | 0% / 80% / 8% | 29% | ❌ **什么都不代表** |

hw2 实测的组内极差：

| 水平 | 三组结果 | 组内极差 | 可信吗 |
|---|---|---|---|
| `-b 1000` | 69% / 80% / 62% | **18%** | ✅ 三组都好 |
| `-lr 5e-3` | 88% / 77% / 62% | **26%** | ✅ |
| `-b 500` | 88% / 31% / 8% | **80%** | ❌ |
| `-lr 2e-2` | 0% / 80% / 8% | **80%** | ❌ **强交互** |

> `lr=2e-2` 那行：同一个学习率，从「九组最佳之一」（#4，80%）到「彻底崩溃」（#8，8%）。
> 它的效果**取决于配的是哪个 batch**，不是它自己的属性。
> L9 把它平均掉，得出「2e-2 不好」—— 方向没错，但掩盖了「2e-2 配 b1000 其实很好」。

---

## 代价：自由度用光了，交互混进主效应

| 设计 | 自由度 | 能估什么 |
|---|---|---|
| 全因子 81 | 80 | 4 个主效应 + 6 个两因子交互 + 更高阶 |
| **L9** | **8** | **只够 4 个主效应**（$4\times 2=8$，加总均值正好 9） |

自由度花光 → **交互效应没地方放，会混进主效应**（术语：confounding／混杂）。

**组内极差大就是混杂在报警。**

## 完整流程七步

| 步 | 做什么 | 关键 |
|---|---|---|
| **1. 缩因子** | 用先验固定已知的，省自由度 | hw2 固定 `-rtg` `-na` `λ=0.99`（前三个实验已证实） |
| **2. 定水平** | 每因子 2–3 档，**用已有证据锚定范围** | 见下 |
| **3. 选设计** | 因子少→全因子；多→正交表；只求最优点→随机搜索 | 4 因子 × 3 水平 → L9 |
| **4. 固定预算** | 让指标可比 | `-n × -b` 恒定 |
| **5. 多指标 + 看曲线** | 单一指标会骗人 | 快 / 稳 / 形态 |
| **6. 诊断可信度** | 组内极差 | 大 → 别信那条主效应 |
| **7. 确认实验** | 正交表给的是**预测**，必须验 | 见下 |

### 第 2 步的三条原则

**A. 3 档而不是 2 档 —— 否则看不出非单调**

hw2 的 batch 主效应：`500=42%`、`1000=71%`、`2000=43%`。

**若只取 2 档 {500, 2000}，得到 42% vs 43% → 结论「batch 无所谓」，完全错误。**
最优在中间，2 档必然漏掉。

**B. 范围要跨过预期最优点，但别浪费在离谱档位**

「离谱」= 你已经知道结果的：`-lr 1.0`（必然发散）、`-b 10`（方差爆炸）、
`--discount 0.5`（horizon 1000 的任务上等于只看前几步）。
**实验预算该花在真正不确定的区间。**

**C. 每一档都要有出处**

hw2 的锚定：

| 因子 | 三档的出处 |
|---|---|
| discount | HalfCheetah 用 0.95、LunarLander 用 0.99、CartPole 默认 1.0 |
| 网络 | 比默认小 / 默认 / LunarLander 那档 |
| batch | 实验 1 已知 5000 太大；PDF §6 警告太小方差高 → 5000 以下取三档 |
| lr | 默认 5e-3 / HalfCheetah 用的 1e-2 / 再翻倍 |

### 第 7 步：确认实验是判据

正交表按主效应挑出的最优组合**通常不在跑过的 9 组里**（hw2 预测的
$\gamma{=}0.99,\ 2/32,\ b1000,\ lr1\text{e-}2$ 就不在）。必须单独跑：

- **确认组优于 9 组最佳** → 主效应模型有效，交互确实弱
- **确认组不如 9 组最佳** → **交互主导**，需要升级设计

## 和逐个调参（OFAT）的对比

| | OFAT | 正交表 |
|---|---|---|
| 做法 | 固定基线，一次改一个因子 | 所有因子**同时**变化 |
| 分离效应靠 | 「其他都没动」 | **平衡性**：每水平的 3 组里其他因子各档各一次 |
| 结论范围 | **只在那个基线附近成立** | 对其他因子取平均，覆盖整个空间 |
| 路径依赖 | 有（先调 A 再调 B ≠ 反过来） | 无 |
| 同样 9 次 | 信息量小 | 信息量大 |

**hw2 的数据直接证明了 OFAT 的危险**：`lr=2e-2` 在 `b1000` 下优秀（#4）、
在 `b500` 下崩溃（#8）。**基点选 b500 还是 b1000，会得出完全相反的 lr 结论。**

## 要交互怎么办：两阶段

| 需求 | 设计 | run 数 |
|---|---|---|
| 只要主效应 | L9 | 9 |
| 主效应 + 部分两因子交互 | L18 / L27 | 18 / 27 |
| 全部交互 | 全因子 | 81 |

**实用路线是两阶段**：

1. **筛选**：L9 便宜地找出哪 1–2 个因子重要（hw2 是 batch 和 lr）
2. **精修**：在这两个因子上做 $3\times3=9$ 组全因子，其他因子固定在主效应最优档

两阶段共 18 组，能拿到那对因子的**完整交互面**，比一上来跑 81 组省 4 倍。

## 视野放大：正交表只是四种方法之一

> 以下为 hw3 续写（2026-09-02）。前半篇以 hw2 实验 4 为例讲的是**归因**。
> 但日常说的「找到合适的超参数」经常指的是另一件事 —— 分不清这两件事，
> 会用错方法、白跑几十个 run。

### 先分辨：argmax 还是归因

| | **优化**（找一组好配置） | **归因**（每个因子多重要） |
|---|---|---|
| 目标 | $\theta^\star = \arg\max_\theta f(\theta)$ | 主效应 $\mathbb{E}[f \mid \theta_i = v]$ |
| 采样分布 | **故意有偏** —— 预算堆到好的区域 | **必须平衡** —— 否则效应混淆 |
| 合适方法 | 随机搜索、Hyperband、贝叶斯优化、PBT | 正交表、因子设计 |
| 交付物 | 一组超参 | 一张主效应图 + 可信度诊断 |

**采样分布的偏与不偏，就是这两件事的分水岭。**

贝叶斯优化在最优点附近密集采样、别处稀疏。拿它的搜索轨迹去算主效应，
算出来的是「**在好配置附近**该因子的效应」，不是全空间的。
反过来，L9 的 9 个点分布均匀，但没有一个是为了「跑得最好」而挑的，
用它找最优点效率极低 —— 它连最优组合都通常不在跑过的 9 组里（见第 7 步确认实验）。

**不要把一次搜索的结果同时当两件事用。**

### 这是什么问题：带噪的黑箱优化

$f:\Theta\to\mathbb{R}$，$f(\theta) =$「按这组超参跑完整训练，返回评价指标」。
四条性质决定了能用什么方法：

| 性质 | 后果 |
|---|---|
| 无梯度 | 排除一切基于梯度的方法 |
| 评估昂贵 | hw3 LunarLander 单 run 17 分钟（4090，实测 493 it/s）—— 核心约束 |
| **有噪声** | $f(\theta)$ 每次调用给的是**随机变量**（seed）。RL 里 seed 方差常与因子效应同量级 |
| 可提前观测 | 学习曲线在跑完之前就给部分信息 —— 唯一对我们有利的性质 |

第三条是 RL 调参区别于监督学习调参**最重要**的地方
（Henderson et al., *Deep Reinforcement Learning that Matters*, AAAI 2018 就是靠这条立论的）。
第四条是 Hyperband 一类方法的全部本钱。

### 方法阶梯

按 hw3 LunarLander 的 17 分钟 / run（50 万步）计：

| 设计 | run 数 | 单 seed 耗时 | 给什么 | 不给什么 |
|---|---|---|---|---|
| 全因子 $3^4$ | 81 | 23 h | 主效应 + 全部交互 | — |
| **L9** | 9 | 2.6 h | 4 个主效应 | 交互（混进主效应）|
| L18 / L27 | 18 / 27 | 5 / 7.7 h | 主效应 + 部分两因子交互 | 高阶交互 |
| 两阶段（L9 → 3×3）| 18 | 5 h | 主效应 + 重要那对的完整交互面 | 其余交互 |
| **随机搜索** | 30 | 8.5 h | 一组好配置；每维 30 个不同取值 | 无偏的主效应 |
| **Successive Halving** | 16 配置 ≈ 8 个 full run | 2.3 h | 一组好配置，同预算多覆盖 2 倍配置 | 被早停砍错的配置 |

## 为什么随机搜索打网格（当你要的是 argmax）

Bergstra & Bengio, *Random Search for Hyper-Parameter Optimization*, JMLR 2012。
直觉只有一句：

**$n$ 个点的 $d$ 维网格，在每一维上只有 $n^{1/d}$ 个不同取值。**

$3^4 = 81$ 个点的网格，在 lr 这一维只探了 **3** 个值 —— 另外 78 次全是这 3 个值的重复。
而 81 次随机采样在 lr 上探了 **81** 个不同的值。

这个差距能兑现，靠的是**效应稀疏原理**：真正重要的因子通常只有一两个。
hw2 实验 4 就是这个形状 —— L9 筛出来重要的是 batch 和 lr 两个（见上节两阶段）。
若只有 lr 真正重要，$3^4$ 网格等于用 81 次评估做了 3 次有效实验。

> **这不构成「随机搜索优于正交表」。** 两者答的不是同一个问题。
> 同样 9 次，正交表给的是**可解释的主效应表**，随机搜索给的是**一个点**。

### 必须在 log 尺度上采样

线性均匀采 $\text{lr} \in [10^{-4}, 10^{-2}]$，**90% 的样本会落在 $10^{-3}$ 以上** ——
等于低端根本没搜。lr、target\_update\_period、hidden\_size 都是**乘性**的，一律 log 均匀采。
代码见文末「可复现」。

## 用曲线换预算：Successive Halving / Hyperband

利用第四条性质：采一批随机配置 → 都跑一小段 → 砍掉差的 → 活下来的接着跑 → 再砍。
（Jamieson & Talwalkar, AISTATS 2016；Hyperband: Li et al., JMLR 2018 —— 后者在外面
再套一层，扫「配置多但每个跑得短」到「配置少但跑得长」的不同权衡。）

### RL 特有的陷阱：早期表现骗人，这直接吃掉 SH 的便宜

监督学习里 $\eta{=}4$、64 个配置、3 个 rung 是很常见的设置：

| rung | 配置数 | 每个跑 | 小计 |
|---|---|---|---|
| 0 | 64 | 31k 步 | 2.0M |
| 1 | 16 | 125k 步 | 2.0M |
| 2 | 4 | 500k 步 | 2.0M |

共 6M 步 = 12 个 full run，却覆盖了 64 个配置。**但这个方案在 LunarLander 上是错的**：

`learning_starts = 20000`，rung 0 设在 31k 步意味着 Q 网络只更新了一万来次、
ε 还在 0.9 以上 —— **这时候砍掉 3/4，砍的是噪声，不是配置。**

更根本的原因写在 hw3 `REPORT.md` §2.4：**train return 反映的是 ε-greedy 行为策略**，
探索期设得长的配置早期看起来天然就差。MsPacman 那张图上，
step 0 处 eval 甚至只有 60 而 train 有 211。

两条硬约束：

- **rung 0 必须显著晚于 `learning_starts`，且晚到 ε 已经降下来**。
  LunarLander 上的下限大约是 125k 步（总步数的 25%）。
- **用 eval return 砍，不用 train return。**

按这个约束重排（$\eta{=}2$、16 个配置）：

| rung | 配置数 | 累计跑到 | 小计 |
|---|---|---|---|
| 0 | 16 | 125k | 2.0M |
| 1 | 8 | 250k | 1.0M |
| 2 | 4 | 500k | 1.0M |

共 4M 步 = **8 个 full run 的预算覆盖 16 个配置**。省了一半，不是省 5 倍。

**结论：RL 里 SH 仍然有用，但便宜远没有监督学习里那么大 —— 因为信号来得晚。**

### PBT：调的是调度，不是定值

Jaderberg et al., *Population Based Training*, 2017（当年就是拿 RL 做的主要实验）。
并行跑一个种群，训练**过程中**把差个体的权重换成好个体的、并扰动其超参。

它的独特之处：产出的是**超参随训练步数变化的调度**，不是一组固定值。
RL 里最优 lr 本来就随阶段变化（早期数据分布快速漂移，后期需要精调），
这个自由度是所有固定值方法拿不到的。代价是要能同时跑一整个种群。

### 贝叶斯优化：在 RL 上收益有限

TPE / GP 靠代理模型加速，前提是目标函数**信噪比够高**。
RL 里 seed 噪声常与因子效应同量级，代理模型会去拟合噪声。
要用的话，必须先做下面这一步。

---

## 噪声底噪：它决定了预算的上限

### 先测，再搜

**用默认配置跑 3–5 个 seed，算评价指标的标准差 $\sigma$。**
任何小于 $\sigma$ 的因子差异都不可信。

这不只是「谨慎」。它有一个定量后果，直接决定预算怎么分。

### 配置数和 seed 数在抢同一份预算

固定总预算 $B = n_{\text{config}} \times n_{\text{seed}}$。
要可靠地分辨大小为 $\delta$ 的效应，每个配置需要的 seed 数约为

$$n_{\text{seed}} \gtrsim \left(\frac{2\sigma}{\delta}\right)^{2}$$

**噪声大、效应小的时候，把预算全砸在「探更多配置」上，
你会得到一份排不出序的结果** —— 探了 60 个配置却不知道哪个真更好，
还不如探 15 个各跑 4 个 seed。

$\sigma$ 没测过就开始搜，等于不知道自己在这个取舍的哪一侧。

### 评价标量必须抗噪

**绝对不要用「最好的那个评估点」当指标** —— 那是对噪声取 $\max$，
选出来的是运气最好的那次评估。上节 ② 里 hw2 的 #8 就是实例：
首次达标全场最快，实际策略已经崩溃。

抗噪的选择（都是某种形式的平均）：

| 指标 | 说明 |
|---|---|
| **后 20% 训练步的 eval return 均值** | 最简单，推荐默认 |
| 学习曲线下面积（AUC） | 同时奖励「快」和「稳」 |
| 首次达标步数 + 达标后维持率 | 两个数配着看，单用第一个会骗人 |

## 怎么选：决策表

| 你的处境 | 用什么 |
|---|---|
| 要在报告里说「哪个因子重要」 | 正交表（L9/L18），配组内极差诊断 |
| 只要一组能用的配置，预算 20–60 run | log 尺度随机搜索 + 抗噪标量 |
| 只要一组配置，预算紧，且曲线早期有信号 | Successive Halving（RL 里 rung 0 要设晚） |
| 能并行跑一个种群，且怀疑最优超参随阶段变 | PBT |
| 因子 ≤ 2，预算够 | 直接全因子，别绕 |
| **$\sigma$ 还没测过** | **先测 $\sigma$，别的都先别做** |

## 可复现

```python
import itertools

# 构造 L9(3^4)：模 3 算术
L9 = [(a + 1, b + 1, (a + b) % 3 + 1, (a + 2 * b) % 3 + 1)
      for a in range(3) for b in range(3)]

def is_orthogonal(rows, n_lev=3):
    """任意两列，所有水平组合恰好各出现一次。"""
    pairs = sorted(itertools.product(range(1, n_lev + 1), repeat=2))
    return all(sorted((r[i], r[j]) for r in rows) == pairs
               for i, j in itertools.combinations(range(len(rows[0])), 2))

print(is_orthogonal(L9))          # True

def main_effect(rows, metrics, col, level):
    """某因子某水平的主效应 = 含该水平的那些组的平均指标。"""
    sel = [m for r, m in zip(rows, metrics) if r[col] == level]
    return sum(sel) / len(sel)

def within_spread(rows, metrics, col, level):
    """组内极差 —— 越大说明该主效应越不可信（交互在作祟）。"""
    sel = [m for r, m in zip(rows, metrics) if r[col] == level]
    return max(sel) - min(sel)
```

### log 尺度采样与噪声底噪（hw3 续写，尚无仓库实现）

```python
import numpy as np

def sample_config(rng):
    """随机搜索：乘性超参一律 log 均匀，不要线性均匀。"""
    return {
        "learning_rate":       10 ** rng.uniform(-4, -2),      # 1e-4 .. 1e-2
        "target_update_period": int(2 ** rng.uniform(6.6, 14.3)),  # ~100 .. ~20000
        "hidden_size":          int(2 ** rng.integers(6, 10)),     # 64 .. 512
    }

def score(eval_returns, frac=0.2):
    """抗噪标量：后 20% 评估点的均值。不要用 max —— 那是对噪声取极值。"""
    k = max(1, int(len(eval_returns) * frac))
    return float(np.mean(eval_returns[-k:]))

def noise_floor(scores_across_seeds):
    """默认配置跑 3-5 个 seed 得到的 sigma。小于它的因子差异一律不信。"""
    return float(np.std(scores_across_seeds, ddof=1))

def seeds_needed(sigma, delta):
    """要分辨大小为 delta 的效应，每个配置大约需要几个 seed。"""
    return int(np.ceil((2 * sigma / delta) ** 2))
```
